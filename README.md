# GoStack — Node.js Concepts Challenge

A study project developed during the **Rocketseat GoStack** program to practice the fundamentals of Node.js and REST API development.

> **Study project:** this repository was created as part of the GoStack learning path and is preserved as a record of the technologies and concepts practiced at the time.

## What the project does

The API manages an in-memory list of software repositories. Each repository contains a title, URL, technologies and a like counter.

Implemented endpoints include:

- List repositories
- Create a repository
- Update a repository
- Delete a repository
- Like a repository

## Tech stack

- Node.js
- Express
- JavaScript
- CORS
- UUID
- Jest
- Supertest
- Nodemon

## Concepts practiced

- REST API design
- HTTP routes and status codes
- Request parameters and request bodies
- In-memory data manipulation
- Middleware configuration
- Automated API tests
- Basic CRUD operations

## Running the project

Install dependencies:

```bash
yarn
```

Start the development server:

```bash
yarn dev
```

Run the automated tests:

```bash
yarn test
```

Modern Node.js versions may require dependency adjustments because this repository preserves the original course implementation.

## Project context

Created in 2020 while studying Node.js fundamentals in Rocketseat's GoStack program. The code remains close to the original challenge implementation so the repository can document this stage of my technical learning path.
